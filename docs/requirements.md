# 概要

AI 支援開発の個人学習プロジェクト。

このアプリケーションは、犬の飼い主が以下を記録できるようにする:

* 日々の健康状態
* 食事
* 薬
* 症状
* 通院
* 散歩履歴

このプロジェクトでは以下を重視する:

* 保守しやすいアーキテクチャ
* シンプルな実装
* フロントエンド/バックエンドの明確な分離
* Docker ベースの開発
* 反復的な MVP 開発

---

# 技術制約

* Vue 3 + TypeScript
* FastAPI
* PostgreSQL
* Docker Compose

---

# アーキテクチャ方針

* 拡張性より保守性を優先する
* 過剰な抽象化を避ける
* MVP を優先する
* シンプルなリレーショナルデータモデリング
* バックエンド主導の API 設計

---

# ドメイン概念

## Owners

飼い主は複数の犬を管理できる。

## Dogs

犬は複数の飼い主に紐づけられる。

## Events

犬の活動は event として保存する。

例:

* 食事
* 散歩
* 薬
* 症状
* 通院
* メモ

シンプルにするため、event type は初期段階では固定する。

---

# 現在の MVP スコープ

## 目的

犬の飼い主が犬を管理し、健康関連の event を記録できる。

## 含めるもの

- owner 管理
- dog 管理
- owner-dog の関係
- owner と dog の登録ページ

## 含めないもの

* event 記録
* event 履歴表示
* 認証
* 通知
* 分析
* AI 診断
* custom event type
* 管理ダッシュボード
* 本番インフラ
