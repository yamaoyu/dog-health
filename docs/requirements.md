# 要件

このドキュメントは、プロダクト目的、MVPスコープ、機能別要件への入口を管理する。技術構造は `docs/architecture.md`、database schemaは `docs/schema.md`、開発フローは `docs/development.md` を参照する。

## 概要

このアプリケーションは、犬の飼い主が犬を管理し、健康関連の記録を残せるようにする。

記録対象の例:

- 日々の健康状態
- 食事
- 薬
- 症状
- 通院
- 散歩履歴

## 重視すること

- 保守しやすい構成
- シンプルな実装
- フロントエンド/バックエンドの明確な分離
- Dockerベースの開発
- 反復的なMVP開発

## ドメイン概念

### Owners

飼い主は複数の犬を管理できる。

### Dogs

犬は複数の飼い主に紐づけられる。

### Events

犬の活動はeventとして保存する。

例:

- 食事
- 散歩
- 薬
- 症状
- 通院
- メモ

シンプルにするため、event typeは初期段階では固定する。

## 現在のMVPスコープ

### 目的

犬の飼い主が犬を管理し、健康関連のeventを記録できる。

### 含めるもの

- owner管理
- dog管理
- owner-dogの関係
- ownerとdogの登録ページ

### 含めないもの

- event記録
- event履歴表示
- 認証
- 通知
- 分析
- AI診断
- custom event type
- 管理ダッシュボード
- 本番インフラ
